# 圆角矩形管公开数据来源登记

> 登记日期：2026-10-11
>
> 用途：公开工程参考数据和公开型材表对照，不是本项目的真实实验数据。

## 1. 当前判定

用户提供的六张“方管、矩形管规格”图片暂不作为模型验证真值，原因如下：

1. 图片没有可追溯的发布机构、标准编号、版本、网址、发布日期或许可证信息。
2. 表中 `50 x 30 x 3` 的面积为 `4.44 cm²`。尖角等壁厚矩形管公式
   `A = 2t(B + H - 2t)` 给出 `444 mm² = 4.44 cm²`，说明该行至少与尖角理想化公式一致。
3. 图片没有外圆角半径、内圆角半径或圆角定义，无法与本项目的实际圆角截面模型一一对应。
4. 因此图片可用于检查“单位、列含义和数量级是否合理”，不可直接用来宣称当前圆角公式已被公开数据验证。

## 4. 允许的后续使用方式

### 可以做

- 选取公开表中明确标识为热轧 RHS 的规格，做单位换算和数量级对照。
- 将公开的面积、单位质量、惯性矩、截面模量与团队工具输出逐项比较。
- 在报告中写成“与公开工程参考型材表的数值对比”。
- 对圆角半径未知的标准型材，单独标记为“标准型材对照案例”，不回填为任意 `outer_corner_radius_mm`。

### 不可以做

- 把用户图片直接称为标准或制造商数据。
- 把公开型材表对照写成“真实实验验证”。
- 用没有圆角半径定义的数据直接证明当前圆角几何公式准确。
- 混合热轧型材、冷弯型材、尖角公式和实际圆角公式而不标注截面类别。
- 从图片反推一个圆角半径，再把反推值当作原始公开数据。

## 5. 下一步

下一步建立一个小型、可复现的对照数据集：先只选主来源中字段完整且能明确确定弯曲轴的 2--3 个规格；记录原始单位、工具输入、工具输出、参考值、绝对误差、相对误差和适用边界。该对照不会修改计算工具，也不会替代圆角模型的几何定义。
