# 悬臂支架确定性力学模型 v1

## 适用范围

本模型用于比赛演示和可复现软件验证，不等同于生产级有限元分析、实体试验或安全认证。对象是固定端矩形截面悬臂梁，载荷为自由端竖向集中力。

## 输入与单位

| 参数 | 符号 | 单位 | 说明 |
|---|---:|---:|---|
| 端部载荷 | `load_n` | N | 取正值；模型使用载荷绝对值 |
| 悬臂长度 | `length_mm` | mm | 固定端到载荷作用点距离 |
| 截面宽度 | `width_mm` | mm | 矩形截面水平尺寸 |
| 截面高度 | `height_mm` | mm | 矩形截面抗弯高度 |
| 弹性模量 | `youngs_modulus_gpa` | GPa | 线弹性材料参数 |
| 屈服强度 | `yield_strength_mpa` | MPa | 用于简化安全系数 |
| 密度 | `density_kg_m3` | kg/m³ | 用于质量计算 |
| 泊松比 | `poisson_ratio` | 1 | 用于空心截面弹性局部屈曲筛查 |

## 计算公式

统一换算到SI单位后：

1. 矩形截面惯性矩：`I = b*h^3/12`；
2. 截面抵抗矩：`W = b*h^2/6`；
3. 固定端最大弯矩：`M = F*L`；
4. 最大弯曲应力：`sigma = M/W`；
5. 自由端最大挠度：`delta = F*L^3/(3*E*I)`；
6. 体积：`V = b*h*L`；
7. 质量：`mass = density*V`；
8. 简化安全系数：`safety_factor = yield_strength/sigma`。

## 约束判定

工具只根据调用方明确提供的约束判定：

- `max_deflection_mm`：挠度不大于该值；
- `min_safety_factor`：安全系数不小于该值；
- `max_mass_kg`：质量不大于该值。

约束边界采用包含关系。所有数值必须有限且大于零。工具返回公式版本、单位、输入回显、指标、约束逐项结果和总体状态，便于AGH和模型复核。
