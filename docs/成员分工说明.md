# 成员分工说明

> 作品名称：机械结构设计智能体（Mechanical Agent）
> 参赛组别：本科生组
> 团队人数：2 人
> 作品架构：Agnes 模型 + Agnes Harness（AGH）运行底座 + 团队自研确定性工程工具

## 二、张宇嘉（队长）：力学建模与核心算法负责人

负责作品的力学理论根基、核心计算工具与计算正确性，并承担项目总体架构与进度统筹。

1. **总体统筹**：负责选题与技术路线、系统总体架构设计、任务拆解与进度管理，组织方案评审、联调与答辩；
2. **力学模型推导**：建立 Euler-Bernoulli 悬臂梁解析模型（v1）与实际圆角空心矩形截面力学模型（v2），负责截面积、惯性矩、中性轴、截面模量等几何与力学量推导，统一单位与符号约定；
3. **局部屈曲理论**：基于 EN 1993-1-5 弹性薄板理论，实现翼缘与腹板分别计算的局部屈曲工程筛查；
4. **材料库建设**：建立 S235、S355、304 不锈钢、6061-T6 铝、7075-T6 铝、Ti-6Al-4V 六种工程参考材料参数库；
5. **核心工具开发**：
   - `cantilever_calculator`：实心矩形截面悬臂单点静力计算；
   - `hollow_cantilever_calculator`：实际圆角空心矩形截面单点计算与局部屈曲筛查；
   - `fe_beam_cantilever`：一维 Euler-Bernoulli 梁单元有限元复核（单元刚度矩阵、带选主元高斯消元、单元内力恢复、网格收敛性与解析解双链路对比）；
6. **正确性把关**：管理公式与工具版本号，对关键数值进行独立复算，保证计算结果正确、可复现、可审计。

## 三、马文琪：Agent 工程与集成验证 / 文档负责人

负责作品在 AGH 上的工程化落地、智能体闭环、测试验证以及全部文档与演示材料交付。

1. **AGH 插件集成**：负责插件 `index.mjs` 工具注册、输入/输出 JSON Schema 定义、包打包/信任/启用流程，以及跨平台、非交互式 CLI 兼容性处理；
2. **Agnes 闭环调试**：设计任务拆解与提示词、编排工具调用顺序，打通“约束校核—参数寻优—失败重规划/无解判定—有限元复核—生成报告”的完整执行闭环；
3. **工程化工具开发**：
   - `design_search` / `hollow_design_search`：候选尺寸网格枚举与寻优；
   - `design_sensitivity` / `hollow_design_sensitivity`：设计参数敏感性分析；
   - `manufacturing_tolerance` / `hollow_manufacturing_tolerance`：制造与载荷公差、边界工况验证；
   - `design_dossier`：确定性 Markdown/HTML 工程报告生成；
4. **测试与验证**：编写 88 项单元测试与 12 项插件注册/演示/故障注入测试，组织端到端闭环验证；完成 SCI / Steel for Life、Alpine Pipe 公开型材数据对照及来源登记、验证报告；
5. **文档与交付**：撰写 README 与 docs 文档，负责演示视频脚本、录制剪辑与字幕，整理报名表（作品简介、作品详情、成员分工）等提交材料。

## 四、协作机制

- **共同完成**：选题与需求定义、总体架构（Agnes 模型 + AGH 底座 + 自研工具）设计、技术选型与方案评审；
- **交叉质量控制**：两人互相进行代码审查与结果复核，关键数值由一方实现、另一方独立复算；
- **联合联调**：共同完成 AGH 全链路联调、演示彩排与问题修复；
- **贡献占比**：两位成员各占 50%。张宇嘉侧重高难度力学内核、核心算法与项目统筹，马文琪侧重系统集成、工具工程化与测试交付，工作量相当。
