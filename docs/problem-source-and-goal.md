# 问题来源与目标

## 一、问题来源

机械结构初步设计通常需要在载荷、尺寸、材料、强度、刚度和质量之间反复权衡。以悬臂支架为例，设计人员往往需要经历“给定工况—选择尺寸和材料—计算应力与变形—检查安全系数—修改方案—重新校核”的循环。传统流程中，参数修改、边界工况检查和计算结果整理容易依赖人工经验，存在以下工程问题：

1. 设计约束分散在任务描述、计算表格和个人经验中，容易遗漏变形、强度或质量等约束；
2. 单个方案满足约束，并不代表在载荷上限、尺寸边界或材料切换等边界条件下仍然满足要求；
3. 方案失败后，下一步应修改哪个参数、重新调用哪项计算、何时判定无可行解，缺少可追踪的自动化流程；
4. 计算结果、失败原因和重新规划过程如果没有结构化记录，难以复核，也难以形成演示证据。

本项目来源于上述机械结构初步设计与校核需求。由于比赛周期内没有实体设备和真实实验数据，项目采用参数、材料和载荷均可追溯的合成工程案例，并使用团队独立开发的确定性力学计算工具进行演示。演示对象限定为具有明确边界条件和解析公式的悬臂支架，用于验证智能体任务闭环能力，而不是替代工程认证、实体试验或生产级有限元分析。

## 二、项目目标

本项目拟构建“Agnes + AGH驱动的机械结构仿真参数寻优与边界工况自动验证智能体”。用户输入载荷、尺寸范围、材料候选、允许变形、最低安全系数和质量上限后，系统应完成以下目标：

1. **自动拆解设计任务**：由AGH调用的模型理解目标和约束，形成可执行的工具调用计划；当前实现选择Agnes模型；
2. **调用确定性工程工具**：由AGH调度团队独立开发并注册的参数校验、候选方案生成、结构指标计算、约束校核和证据汇总工具；
3. **完成边界工况验证**：除名义工况外，检查载荷、尺寸和材料候选范围内的边界组合，返回应力、变形、质量、安全系数及约束状态；
4. **支持失败后的重规划**：当候选方案违反约束、工具报错或返回数据异常时，将结构化反馈交给Agnes，由Agnes决定调整参数、重试、调用后续工具、报告无解或终止任务；
5. **输出可复核证据**：保存输入参数、工具版本、公式版本、工具调用顺序、结构化返回、约束判定、失败原因、重规划过程和最终结论，支持现场演示和赛后复核；
6. **验证任务是否真正完成**：只有当候选方案通过全部约束、边界工况检查完成且证据字段完整时，系统才输出“完成”；否则输出带失败证据的“未完成/不可行/需人工介入”状态，不将异常结果误判为成功。

## 三、预期成果边界

项目预期形成一个可在AGH中运行的最小可验证闭环：

> 顶层设计任务 → Agnes拆解规划 → AGH调度工具 → 团队工具确定性计算 → 结构化返回 → Agnes校验 → 成功、重试、重规划或终止。

运行和演示阶段必须以AGH作为智能体运行与执行底座。模型负责任务理解、规划、参数决策、结果校验和重规划；当前实现选择Agnes模型。所有计算、校验和证据生成逻辑由团队独立开发。项目当前不接入额外的第三方模型组件，以降低部署和验证风险；这属于本项目的实现选择，不是赛事对模型的强制限制，也不主张由智能体自动生成底层工程代码。

## 四、可直接粘贴到报名表的精简版

机械结构初步设计需要在载荷、尺寸、材料、强度、刚度和质量之间反复权衡。以悬臂支架为例，人工流程通常需要不断修改参数、计算应力与变形、检查安全系数，并重新验证边界工况；方案失败后的调整依据、无解判定和全过程证据也不易统一记录。针对这一问题，本项目构建基于AGH和模型层的机械结构仿真参数寻优与边界工况自动验证智能体，当前实现选择Agnes模型。用户输入载荷、尺寸范围、材料候选和安全约束后，由AGH调用模型拆解任务并规划步骤，AGH调度团队独立开发的确定性参数校验、结构计算、候选筛选和证据生成工具，系统自动返回应力、变形、质量、安全系数及约束状态。当方案失败或工具异常时，模型根据结构化反馈重新规划、重试或终止，并保留可复核的运行证据。项目采用合成工程案例和明确解析公式进行验证，目标是证明智能体能够完成可执行、可验证、可追踪的机械设计任务闭环，而非替代实体试验或生产级有限元认证。
