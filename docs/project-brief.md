# 项目简介

## 暂定名称

Agnes + AGH驱动的机械结构仿真参数寻优与边界工况自动验证智能体。

## 要解决的问题

机械结构初步设计通常需要反复修改尺寸和材料，再进行强度、刚度、质量和不同载荷工况的检查。本项目不依赖当前无法获得的实体设备或实验数据，而是通过一个边界明确、可复现的悬臂支架确定性力学模型，演示完整的智能体工程任务闭环。

报名表可直接使用的“问题来源与目标”完整稿见：[`docs/problem-source-and-goal.md`](problem-source-and-goal.md)。该稿明确区分了机械工程问题来源、项目目标、预期成果和合成案例边界，避免将演示模型表述为生产级有限元或实体试验结论。

## 目标任务

针对用户给出的载荷、尺寸范围、材料候选、允许变形、最低安全系数和质量上限，系统需要：

1. 检查输入参数和单位；
2. 在给定范围内生成候选参数；
3. 使用有明确公式和版本号的确定性模型计算结构指标；
4. 检查正常工况和边界工况；
5. 以结构化数据返回约束失败项；
6. 由Agnes决定是否调整参数、调用下一工具、报告可行方案，或以不可行说明终止；
7. 生成计算结果、运行日志和可复现报告。

当前已冻结悬臂支架解析模型 v1，并实现第一个团队工具 `tools/cantilever_calculator.py`。模型公式、单位、材料演示参数和适用边界见 [`docs/mechanics-model-v1.md`](mechanics-model-v1.md)。

## 职责边界

- 模型层：理解任务、拆解计划、选择工具、决定参数、校验结果、判断失败和重新规划；当前实现选择Agnes模型，后续是否接入其他模型以AGH能力和赛事规则为准；
- AGH：负责模型和工具的编排、经过授权的工具执行、任务状态和执行记录；
- 参赛团队：独立开发所有工程工具、接口Schema、确定性计算、验证标准、集成代码、测试和证据；
- AGH是运行与执行底座。当前版本不接入额外的第三方模型组件，以降低部署和合规风险；这属于项目实现选择，不是赛事硬性限制。

## 初始范围限制

- 只演示一个对象：采用明确简化力学模型表示的悬臂支架；
- 不声称这是可直接用于生产的CAD或有限元分析结果；
- 不做真实设备控制或物理安全决策；
- 不依赖外部数据集，测试输入为人工构造的工程案例，并明确标注为合成案例；
- 材料参数和简化假设必须在最终验证前注明来源或标注为假设。

## 验收证据

- 至少三个连续的AGH工具执行步骤；
- 一个返回可行方案或有依据的不可行结论的正常案例；
- 边界案例和失败注入案例；
- 结构化工具输入、工具输出和AGH执行记录；
- 对关键数值进行独立复算；
- 展示一次方案失败后由Agnes读取反馈并重新规划，或展示明确的终止状态；
- 按赛事提交要求记录实际使用的模型名称、版本和参与环节；当前计划记录Agnes模型。
