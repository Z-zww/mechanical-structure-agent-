# 验证计划

## 测试类别

| 类别 | 示例 | 预期行为 |
|---|---|---|
| 正常案例 | 载荷、尺寸、材料和约束均合法 | 返回确定性指标和明确的约束状态 |
| 边界案例 | 载荷或尺寸取允许范围边界 | 正确处理边界包含关系和单位 |
| 非法输入 | 缺失、负值、非有限值或相互矛盾的参数 | 返回结构化错误，不生成伪成功结果 |
| 约束失败 | 强度、变形或质量超过限制 | 返回实际值、限制值和失败约束 |
| 工具失败 | 超时、异常或返回字段不完整 | AGH和Agnes能够看到失败，不误判为完成 |
| 重规划 | 第一个候选失败，其他候选可行 | Agnes读取反馈并再次调用工具 |
| 无可行解 | 全部候选都无法满足约束 | Agnes带证据终止，不宣称任务成功 |

## 需要保存的证据

- 测试案例编号和版本化输入；
- 工具名称、参数、结构化输出、状态和执行耗时；
- 计算公式版本、单位、中间量和约束；
- 显示连续工具调用和Agnes参与过程的AGH执行记录；
- 脱敏后的截图或演示录屏。

不要在本目录保存API密钥、AGH完整本地目录或学生个人隐私信息。
