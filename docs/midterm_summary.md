# 项目中期小结

更新时间：2026-10-09

## 一、项目定位

- 组别：本科生组
- 主赛道：工程设计与数字世界
- 具体方向：数字孪生与仿真到现实
- 项目对象：矩形截面悬臂支架
- 核心目标：让 Agnes 通过 AGH 调度团队开发的确定性工程工具，完成候选方案搜索、敏感度分析、公差验证和失败后重规划。

运行/演示阶段只使用赛事指定的 Agnes 模型。工程计算、工具代码和异常处理由团队实现。

## 二、目前已经完成

### 1. 工程计算工具

已完成五个确定性工具：

1. `calculate_cantilever`：计算应力、挠度、质量和安全系数；
2. `search_design_candidates`：遍历候选尺寸并按质量、挠度排序；
3. `analyze_design_sensitivity`：分析载荷、长度、宽度和高度的相对影响；
4. `verify_manufacturing_tolerance`：枚举载荷、长度、宽度和高度公差边界。
5. `generate_design_dossier`：根据结构化结果生成确定性 Markdown/HTML 工程报告。

已加入的边界保护：

- 零公差边界自动去重；
- 长度公差纳入验证；
- 有效尺寸不得小于 `0.01 mm`；
- 严重度计算设置有限值保护；
- 工具输入和错误返回结构化。

